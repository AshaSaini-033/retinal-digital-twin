# Retinal Digital Twin — Step 1

1. Download dataset from https://doi.org/10.6084/m9.figshare.30582035
2. Open `notebooks/01_load_dataset.ipynb` in Google Colab or Jupyter.
3. Run cells from top to bottom. In Colab, upload the downloaded ZIP when prompted. In local Jupyter, put it in `data/`.
4. Review detected file formats and sample array shape.

Paper: https://doi.org/10.1038/s41597-025-06497-1

This ZIP contains only Step 1 (loading and inspection), not model training.
